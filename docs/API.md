# API Reference (moved)

This file documented the pre-pivot coding-agent API surface: `/api/agents`,
`/api/agent-cards`, `/a2a/tasks`, and `x-org-id` header auth. That surface
belongs to the repo's original coding-agent platform, before the thesis
pivoted to LATAM commerce in April 2026, and none of it describes the
current product.

The current API is sessions + meta-tools, documented at
[docs.codespar.dev](https://docs.codespar.dev). Start with the API section:
[docs.codespar.dev/docs/api/sdk](https://docs.codespar.dev/docs/api/sdk).

The OSS runtime's own surface (sessions, MCP bridge, test mode) is described
in [README.md](../README.md) at the repo root.

The old endpoint tables live in git history if you need them; this file is
intentionally a stub.
